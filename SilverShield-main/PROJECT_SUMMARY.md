### Message Analyzer
```
INPUT PHASE:
  ├─ Accept message text (any length)
  ├─ Optional source selection (SMS, WhatsApp, Email, etc.)
  └─ Submit for analysis

ANALYSIS PHASE:
  ├─ Pattern matching (70+ keywords)
  ├─ Algorithm scoring (5 categories)
  ├─ Risk calculation (0-100)
  └─ Confidence assessment

OUTPUT PHASE:
  ├─ Risk level display (Low/Medium/High)
  ├─ Detected patterns breakdown
  ├─ Specific keywords found
  └─ Actionable recommendations
```

### Recommendation System
```
HIGH RISK:
  ├─ DO NOT click links
  ├─ DO NOT share personal info
  ├─ Delete immediately
  ├─ Block sender
  └─ Report to authorities
```

## 🎨 Design Decisions Rationale

### Why These Colors?
- **Blue**: Trust and security (universal across cultures)
- **Gold**: Warmth and accessibility (high contrast)
- **Green**: Safety and reassurance
- **Silver**: Reflects brand name and sophistication
- **Contrast**: WCAG AAA (exceeds accessibility standards)

### Why This Typography?
- **18px Base**: Readable for seniors without zoom
- **1.6 Line Height**: Improves readability
- **Clear Hierarchy**: H1 > H2 > H3 > P
- **System Fonts**: Fast loading, universal

### Why This Layout?
- **Single Column**: Reduces cognitive load
- **Large Buttons**: Touch-friendly (44px+)
- **Generous Spacing**: Breathing room for eyes
- **Clear Sections**: Logical information flow
